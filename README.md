# Modelportefeuille

Deze tak bewaart de modelportefeuille van Aandeel Signaal. Niet met de hand wijzigen.

- `staat.json`: de echte modelportefeuille vanaf de start. Elke nacht aangevuld door de nachtelijke update (`modelportefeuille.js`); bestaande aankopen en verkopen worden nooit herschreven.
- `terug.json` / `terug.md`: de teruggerekende versie vanaf 2018 (workflow "Modelportefeuille terugrekenen", handmatig).
